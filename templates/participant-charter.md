## Capability reality

Mode: conversation / workspace / native-agents, based on actual evidence.
Known limits: record missing or unverified persistence, agents, scheduler, sources or deletion.
Native role IDs and instruction versions: only actual successfully created roles.

Actual processing exposure: virtual roles share the host conversation; a host running
the CLI sees its output. Logical recipient labels do not create security isolation.
Record which host/provider receives information. If CoS must not see certain data, do
not route it through CoS-visible tools; require genuinely isolated authorized processing.

## Validity and controls

Current permission must be scoped by purpose, data, recipient and retention. Reuse valid
choices without unnecessary repeated questions. A later revocation takes precedence over
this older record. Stopping messages, stopping a topic, pausing processing, revoking a
source and deleting state are separate controls. Explain actual storage/provider limits.

Never fill an unknown with the author's example or infer permission from silence. Do not
collect identity documents, credentials or a complete health history to complete a form.
