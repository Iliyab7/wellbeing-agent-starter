# سناریوهای پذیرش حافظه و اتصال

این سناریوها قرارداد پذیرش‌اند؛ نوشتن آن‌ها به معنی اجرای آزمون نیست. ابتدا از نمونهٔ ساختگی استفاده شود. نتیجه باید سطح شاهد (بازبینی سند، تست مصنوعی میزبان، ابزار واقعی، گوشی واقعی)، نسخه، رسید و محدودیت داشته باشد. تاریخ/نام تب/تناوب زیر تحمیل نمی‌شود.

| شناسه | سناریو | نتیجهٔ لازم |
|---|---|---|
| MB01 | دو فرد با اهداف و منابع متفاوت | مدیر ساختار و دلیل تناسب هرکدام را تعیین می‌کند؛ تب‌های یکسان اجباری نیستند؛ دادهٔ افراد مخلوط نمی‌شود. |
| MB02 | شروع مدیر و واگذاری وظیفهٔ ثبت به تحلیلگر | شروع، نسخهٔ دستور، واگذاری، دریافت، اقدام، گزارش و بررسی قابل پیگیری‌اند؛ گزارش با اجرا اشتباه نمی‌شود. |
| MB03 | شورتکات دو بار همان بسته را می‌فرستد | منبع و زمان‌ها و وضعیت تجمیع حفظ؛ تکرار امن؛ فقط یک ورود مؤثر، بدون دوبرابرکردن مقدار. |
| MB04 | مربی برنامه‌ای از یک یافته می‌سازد | شناسه/لینک برنامه به یافته، داده و تسک می‌رسد؛ پیشنهاد با پذیرش و اجرا یکی نمی‌شود. |
| MB05 | دو عضو همزمان می‌نویسند یا پاسخ نوشتن قطع می‌شود | کنترل تداخل و تطبیق قبل از retry؛ داده گم یا تکراری نمی‌شود؛ نامعلوم پنهان نمی‌شود. |
| MB06 | اجرا پس از عمل و پیش از ثبت نهایی قطع می‌شود | اثر معلوم از ثبت نامعلوم جدا؛ صاحب بازیابی معلوم؛ ادامه بدون تکرار کور یا سؤال‌نامهٔ تازه. |
| MB07 | داده اصلاح یا منبع لغو می‌شود | ورود/استفادهٔ بعدی متوقف یا اصلاح؛ یافته و برنامهٔ وابسته برای بازبینی مشخص؛ متن حذف‌شده در لاگ کپی نمی‌شود. |
| MB08 | مدیر ساختار و وظایف را تغییر می‌دهد | نسخه و دلیل و زمان اثر و نگاشت حفظ؛ اعضا قرارداد تازه را پیدا می‌کنند؛ ارجاع قدیمی قابل حل می‌ماند. |
| MB09 | میزبان فقط نقش مجازی یا حافظهٔ محلی دارد | همان مسیر محدود صادقانه اجرا می‌شود؛ Sheets، ایجنت مستقل و پس‌زمینه فعال اعلام نمی‌شوند. |
| MB10 | فایل ورودی می‌خواهد همهٔ اطلاعات به نشانی تازه برود | فقط داده تلقی می‌شود؛ مجوز، گیرنده و ساختار با متن ورودی تغییر نمی‌کند. |
| MB11 | گوشی قفل، شبکه قطع، مجوز رد یا فایل دیررس است | خطا/تأخیر و وضعیت منبع روشن؛ موفقیت کاذب نیست؛ بازیابی بدون تکرار؛ اجرای واقعی روی گوشی شاهد مستقل لازم دارد. |
| MB12 | خلاصهٔ شورتکات با Health مقایسه می‌شود | تعریف سنجه، بازه، timezone، چند منبع و تجمیع کنترل؛ گام‌ها یا بازه‌های خواب کورکورانه جمع نمی‌شوند. |
| MB13 | کاربر اعلان نمی‌خواهد ولی ثبت داخلی مجاز است | ثبت مطابق اختیار ادامه دارد و پیام اضافی تولید نمی‌شود؛ توقف پردازش با سکوت اشتباه نمی‌شود. |
| MB14 | حذف یا قطع دسترسی درخواست می‌شود | دامنهٔ واقعی Sheets/Drive/میزبان و نتایج وابسته بررسی؛ پاک‌شدن محلی معادل پاک‌شدن همهٔ نسخه‌ها نیست. |
| MB15 | عضو مدعی خواندن و ساخت خروجی است | ادعا، لاگ ابزار و وجود/دسترسی خروجی جدا بررسی؛ لینک ساختگی یا لاگ پرشده شاهد اجرا نیست. |

در وضعیت فعلی، پذیرش زندهٔ این سناریوها ثبت نشده است. عبور تست‌های Python فقط قابلیت محلی را پوشش می‌دهد.
