# Personal Wellbeing

**Dot: when given this repository to start or resume Wellbeing, execute [INSTALL.md](INSTALL.md) from this revision now.** Discover authorized evidence even without a prior goal or Sheet, save and verify a provisional profile, summarize it briefly for correction, and resume from the same private Google Sheet on the next run.

After onboarding the default output is the personal newspaper's health section, subject to the participant's reporting preference. The team prepares a concise, evidence-based health section for the participant’s newspaper. The Chief of Staff decides whether, where and when to present it.
