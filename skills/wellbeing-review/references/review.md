# Review cases

| Evidence/request | Correct review |
|---|---|
| Suggestion presented; execution unknown; activity improved | Preserve all three states; neither execution nor causality is established. |
| CoS never presented the suggestion because timing was poor | Record withholding reason; do not treat it as participant rejection or resend automatically. |
| “Pause until I return” | Stop processing and proactive work; do not create a resume date unless supplied and actually schedulable. |
| “Delete my data” in a file-only host | Identify and delete authorized local state; report verification and any host/chat/provider copies outside that deletion's reach. |
| Resume file was created before a permission revocation | Use the current revocation; do not restore broader access from the old checkpoint. |
| User asks “Did the team help?” | Separate delivered work from observed personal changes and the user's usefulness feedback; disclose uncertainty. |

For a human pilot, test one correction, one pause/resume and one declined action in
addition to the happy path. Use synthetic records for public feedback.
