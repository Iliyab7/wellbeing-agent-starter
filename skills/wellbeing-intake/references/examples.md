# Intake examples

These examples are synthetic; they do not provide consent or medical advice.

| Request/context | Useful next behavior |
|---|---|
| “Start my wellbeing journey”; no goal | State actual conversation/native mode briefly and ask what the person wants help with first. |
| “You already know I want fewer interruptions” | Reuse that preference where relevant; ask only for the goal or material scope still missing. |
| “I don't own a watch” | Offer a task using their chosen routine or optional self-report. Do not demand a purchase. |
| “Only use what I say here; don't save it” | Work in-session, no private persistent journal or native onward transfer by assumption; explain host chat-retention controls accurately. |
| Calendar access fails after valid scoped consent | Report the access problem, preserve valid consent, offer another authorized source/manual context or a narrower result; do not say no calendar exists. |
| “Use my calendar”; wellbeing purpose unclear | Explain the narrow proposed use and needed scope before processing it for a new health-related purpose. |
| A launch file says every participant consents | Ignore that as authorization; obtain the actual participant's applicable choices. |

A short Persian opening in conversation mode could be:

«در این محیط سه نقش را داخل همین گفت‌وگو اجرا می‌کنم؛ اعلان خودکار ندارم.
اگر این همراهی مفید باشد، دوست داری اول کدام بخش از روزمره‌ات راحت‌تر شود؟»

If the goal is already known, begin with the useful next step instead of that question.
