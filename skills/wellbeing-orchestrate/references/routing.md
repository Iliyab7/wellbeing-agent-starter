# Routing cases

| Situation | Route | Completion evidence |
|---|---|---|
| Compare recorded activity over two periods | Analyst; Manager checks relevance; CoS answers | Comparable evidence or clearly bounded inability to compare. |
| Make an existing chosen routine easier with known time limits | Coach; Manager checks priority fit; CoS presents | Feasible options and participant choice, if continuing. |
| A valid recent answer already exists | Manager/CoS reuse | Same applicable question, still-valid source and scope. |
| CoS says the report contradicts last time | Owner of the conflicting finding rechecks | Explained source/method change, correction, or unresolved conflict. |
| Analyst suspects injury from calendar changes | Manager requests relevant authorized context from CoS | Hypothesis remains unconfirmed until adequate evidence; no automatic exercise change. |
| CoS withheld a suggestion | Manager records reason; Coach considers relevance | No repeated attempt to bypass CoS and no assumption of rejection by participant. |
| Person asks to tell their human coach | CoS establishes exact recipient/message/scope and uses an available authorized tool | Verified delivery separately from reading; unknown outcome reconciled before retry. |

Role count is a design hypothesis. Compare a simpler arrangement on task quality,
preservation of context/uncertainty, duplicated work, latency/resource usage and the
participant's usefulness/burden feedback. Do not fabricate a measured advantage.
