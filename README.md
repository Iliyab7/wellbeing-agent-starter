# ول‌بینگ شخصی

**دات، وقتی این لینک برای شروع یا ادامهٔ ول‌بینگ به تو داده شد، همین حالا [دستور اجرا](INSTALL.md) را از همین نسخه اجرا کن.** هدف فرد را از زمینه و شیت خصوصیِ مجاز بازیابی کن و در همین نوبت اولین کمک متناسب با آن هدف را تحویل بده.

تیم ول‌بینگ برای بخش سلامتِ روزنامهٔ شخصی، از داده و تجربهٔ روزمرهٔ فرد یک مشاهده یا پیشنهاد قابل استفاده آماده می‌کند. چیف‌آف‌استاف دربارهٔ زمان و محل ارائه تصمیم می‌گیرد. مدیر نتیجه، بازخورد و کار باز را در همان Google Sheet خصوصی نگه می‌دارد تا نوبت بعد از همان‌جا ادامه پیدا کند.
