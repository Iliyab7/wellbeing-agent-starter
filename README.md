# ول‌بینگ شخصی

**دات، وقتی این لینک برای شروع یا ادامهٔ ول‌بینگ به تو داده شد، همین حالا [دستور اجرا](INSTALL.md) را از همین نسخه اجرا کن.** حتی بدون هدف یا شیت قبلی، ابتدا منابع مجاز را بررسی کن و شناخت اولیه را برای تحلیلگر در شیت خصوصی ثبت و بازخوانی کن. سپس کوتاه بگو چه خواندی و چه برداشتی داری تا فرد بتواند آن را اصلاح یا تکمیل کند.

بعد از شناخت اولیه، خروجی پیش‌فرض تیم بخش سلامت روزنامهٔ شخصی است. ترجیح ثبت‌شدهٔ فرد دربارهٔ گزارش و تماس مقدم است. تیم برای این بخش، از داده و تجربهٔ روزمرهٔ فرد یک مشاهده یا پیشنهاد قابل استفاده آماده می‌کند. چیف‌آف‌استاف دربارهٔ زمان و محل ارائه تصمیم می‌گیرد. مدیر نتیجه، بازخورد و کار باز را در همان Google Sheet خصوصی نگه می‌دارد تا نوبت بعد از همان‌جا ادامه پیدا کند.
