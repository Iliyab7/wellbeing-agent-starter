# ول‌بینگ شخصی

**دات، وقتی این لینک برای شروع یا ادامهٔ ول‌بینگ به تو داده شد، همین حالا [دستور اجرا](INSTALL.md) را از همین نسخه اجرا کن.** حتی بدون هدف یا شیت قبلی، ابتدا منابع مجاز را بررسی کن و در همین نوبت اولین کمک مبتنی بر یافته‌ها را تحویل بده.

تیم ول‌بینگ برای بخش سلامتِ روزنامهٔ شخصی، از داده و تجربهٔ روزمرهٔ فرد یک مشاهده یا پیشنهاد قابل استفاده آماده می‌کند. چیف‌آف‌استاف دربارهٔ زمان و محل ارائه تصمیم می‌گیرد. مدیر نتیجه، بازخورد و کار باز را در همان Google Sheet خصوصی نگه می‌دارد تا نوبت بعد از همان‌جا ادامه پیدا کند.

[آزمون دو نوبت در دات](docs/participant-pilot-fa.md) · [English](README.en.md)

در شروع، خودت منابع متصل و مجاز را پیدا کن. تحلیلگر از آن‌ها هم یافتهٔ امروز و هم زمینهٔ ماندگار را استخراج کند. مدیر زمینه را در همان شیت ثبت و بازخوانی کند و برای بازبینیِ بی‌صدا برنامهٔ مشخص بدهد.
