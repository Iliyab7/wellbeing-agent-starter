# Grok or another chat host

**2026-11-08 memory extension:** Read [shared-memory responsibilities](../docs/shared-memory/README.md).
Manager designs/maintains participant-specific Sheets memory and assigns logging duties;
all roles register authorized data, work, exchanges and source-linked outputs. Check actual
read/write/scheduling/intake capabilities; downloading this package does not activate them.
On resume, recover the active structure, valid authority, findings and open tasks. Local and
conversation fallbacks remain available; no universal tab layout is prescribed.

Read [CHAT-STARTER.md](../CHAT-STARTER.md) as participant task instructions, subject to
the host's own higher-priority rules. The host occupies the Chief of Staff role; the team
remains Manager, Analyst and Coach. This file does not assume any Grok product tier,
agent API, scheduler, file storage or connector support.

Use the [English](../prompts/BOOTSTRAP-EN.md) or [Persian](../prompts/BOOTSTRAP-FA.md)
launch prompt. If repository browsing fails, use the complete attached starter. If a
host cannot read the attachment, paste its full text instead; do not pretend the missing
instructions were loaded.

Run [capability discovery](host-capabilities.md). A chat-only host can perform a useful
session with clearly virtual roles and participant-selected manual context. Do not claim
independent agents, reminders or durable history in that mode. Follow scope and privacy
rules even when role perspectives live in one model. Human judgment still comes from
the host model; the deterministic CLI is an optional local record-and-validation layer.

On a move from another assistant, the person provides a private checkpoint and authorizes
the new host's use. Check current permission, source availability and open commitments;
do not re-run a full questionnaire or restore revoked scope from an old checkpoint.

**Verification boundary:** no account-specific Grok runtime was tested by writing this
adapter. Record observed live behavior during the participant's smoke test.
